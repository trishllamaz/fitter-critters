**Fitter Critters**

Website made by Karen Wongso, Kylie Sodano, Michael Leslie, Patricia Tran

**1. User Guide Requirements:**

The user can open the website on any browser.

**2. How to start the system:**

Start the website by using the link https://www.cs.drexel.edu/~pvt26/ci-102-lab-61-group-10/index.html

**3. How to use different features of the system:**

The user can click on the Instruction Page link on the home page or "Need Help?" tab in the navigation bar at any time for help with the website. The user can click on the "Your Closet" tab and press on "Upload Clothes" to upload images of clothing from their camera roll by pressing the "Choose Image" button. The user can select tag(s) and press submit. The clothing shows up on the closet page. The user can edit the image or tag selecting the upper right corner of the clothing, or press on the checkmark and the "Save Outfit" button to save the image(s) into the Favorite page. The user can search for clothing with specific tags using the search bar on top.
